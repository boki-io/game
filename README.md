# Hero Horde (working title)

A 2D survivors-like built in Godot 4 (GDScript). Survive 5 minutes of enemies, level up, and use the
Q / E / R abilities of the Knight. Proof of concept.

## Run it
1. Install Godot 4.7 (`brew install --cask godot` on macOS).
2. `godot --path .` from this folder, or open `project.godot` in the editor and press F5.

## Controls
| Action | Keyboard and mouse | Gamepad |
|---|---|---|
| Move | WASD | Left stick |
| Aim | Mouse | Right stick |
| Dash & Slash / Spin / Slam | Q / E / R | X / Y / Right trigger |
| Pause | Esc | Start |
| Debug overlay | F3 | |

Slash is automatic. Level-up cards: click, keys 1/2/3, or D-pad and confirm.

## Project layout
- `scenes/`: main menu, character select, the game (`main.tscn`), player, enemy, pickups, projectile.
- `scripts/`: `player/`, `enemy/` (brains), `abilities/` (behaviors), `systems/`, `ui/`, `upgrades/`, `characters/`.
- `data/`: tuning as resources: `abilities/`, `enemies/`, `upgrades/`, `characters/`.
- `assets/audio/`: placeholder sound effects, generated by `python3 tools/gen_sfx.py`.
- `docs/`: specs. Start with `spec-0.1.md`, then `spec-0.2.md` (which includes the build status).

## Adding things
- **Enemy:** new `EnemyData` resource in `data/enemies/` with a brain script, then add it to
  `SpawnDirector.enemy_types` in `scenes/main.tscn`.
- **Upgrade:** new `UpgradeData` resource in `data/upgrades/`, then add it to the character's `upgrade_pool`.
- **Character:** new `CharacterData` in `data/characters/`, then list it in `CharacterRegistry`.
